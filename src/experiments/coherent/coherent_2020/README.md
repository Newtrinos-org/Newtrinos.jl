# COHERENT data (CsI[Na] and CENNS-10 LAr)

## `csi/` — CsI[Na] full-dataset release
Ancillary files of arXiv:2110.07730 (v2), the data release of *Measurement of the Coherent Elastic Neutrino-Nucleus
Scattering Cross Section on CsI by COHERENT*, Phys. Rev. Lett. 129, 081801 (2022):
`dataBeamOnC.txt`, `dataBeamOnAC.txt`, `brnPE.txt`, `brnTrec.txt`, `ninPE.txt`, `ninTrec.txt`, `effCoefficients.txt`,
`scintRespCoefficients.txt`, `snsFlux2D.root` (identical file names; the release also contains
`Paper_CEvNSCsI_FullDataset_SupMaterials.pdf`, not copied here).
`snsFlux2D_CSV/` is a CSV conversion of `snsFlux2D.root` made for Newtrinos (used by `sns_flux`). The SNS flux
simulation is described in Phys. Rev. D 106, 032003 (2022).

Index: https://newtrinos-org.github.io/newtrinos-index/records/coherent-csi-2021-data-release/

## `lAr/` — CENNS-10 liquid argon, Analysis A
Files of the Zenodo record doi:10.5281/zenodo.3903810, *COHERENT Collaboration data release from the first detection
of coherent elastic neutrino-nucleus scattering on argon* (v1.0, 2020, CC BY 4.0), companion note arXiv:2006.12659,
for Phys. Rev. Lett. 126, 012002 (2021). All data files are copied unchanged; the release's
`CENNS10DataReleaseCompanion.pdf`, `PlotExtractedData.C` and `readYAMLParameters.py` are not.

Index: https://newtrinos-org.github.io/newtrinos-index/records/coherent-cenns10-lar-data-release/
