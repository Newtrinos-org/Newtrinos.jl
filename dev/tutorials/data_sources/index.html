Data sources

Where every external input of Newtrinos.jl comes from. Each resource is catalogued in the Newtrinos Index, with its licence, all known copies, and a data card describing its intended use and limitations; the comparisons with the published results are on the verifications site.

"Extracted" means the Newtrinos developers read the numbers off published figures (vector paths where possible, scripts next to the data); single numbers quoted in papers are cited in the module source only.
